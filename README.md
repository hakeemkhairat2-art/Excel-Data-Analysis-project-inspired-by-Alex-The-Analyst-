Excel Data Analysis Project (Inspired by Alex The Analyst)

## Project Overview

This project is a recreation of a guided Excel data analysis tutorial by Alex The Analyst.
The focus of this project was not just building a dashboard, but understanding the data cleaning, transformation, and analytical workflow behind it.

The dataset was cleaned, transformed, and analyzed using Microsoft Excel before building an interactive dashboard.

## Data Cleaning Process

The following preprocessing steps were performed:
	1.	Checked for blank values
	2.	Removed duplicates
	3.	Standardized marital status values
	4.	Cleaned gender column (Converted M/F to Male/Female)
	5.	Formatted income column to currency
	6.	Created a new working sheet after cleaning
	7.	Created an Age Bracket column using nested IF statements to reduce dashboard clutter
## Analysis Performed
-Created Pivot Tables to analyze:
-Average Income per Purchase
-Customer Commute Distance
-Customer Age Bracket
-Inserted charts for visualization
-Built an interactive dashboard
-Added slicers for dynamic filtering
-Adjusted layout for readability and presentation


## Key Learning Outcomes
-Importance of structured data cleaning before visualization
-Writing conditional logic using nested IF statements
-Using Pivot Tables for insight generation
-Designing interactive dashboards with slicers
-Understanding that dashboards are the end product — not the core skill
